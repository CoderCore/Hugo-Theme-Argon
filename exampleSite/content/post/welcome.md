# 欢迎使用 Argon Hugo 主题

这是一篇示例文章，用于展示 Argon Hugo 主题的各种功能。

## 特性展示

### 1. 卡片式设计

Argon 主题采用现代化的卡片式设计，让您的内容更加美观易读。

### 2. 响应式布局

主题完全响应式，在各种设备上都能完美显示。

### 3. 深色模式

支持深色和浅色模式切换，保护您的眼睛。

## 代码高亮

```python
def hello_world():
    print("Hello, Argon Hugo Theme!")
    
if __name__ == "__main__":
    hello_world()
```

```javascript
function greet(name) {
    console.log(`Hello, ${name}!`);
}

greet("Argon");
```
